# Omni-G Gap Matrix

**Purpose:** living delta between the business-plan vision, the milestone roadmap, and the current Aggregator/Processor implementation.

**Last Updated:** July 5, 2026 — V2 Step 3 complete: Celery worker runtime is now persistent per worker process; `_run_event` extracted as testable helper; runtime reset on error for clean retries; 3 new lifecycle tests added

## Scope Change (Intentional, June 2026)

The following features were **intentionally removed** as part of the platform generalization from Intelligence Community / threat intelligence to a domain-agnostic knowledge graph:

| Removed Feature | Reason |
|-----------------|--------|
| STIX 2.1 SDO entity types (ThreatActor, Malware, AttackPattern, Campaign, Indicator) | Replaced by open-ended generic entity model; LLM determines type freely |
| STIX-specific fields (`stix_type`, `kill_chain_phases`, `indicator_types`, `created_by_ref` as STIX requirement) | `created_by_ref` kept as `source_id` for provenance; STIX-specific fields dropped |
| TAXII server / inter-agency sharing | Out of scope for general platform |
| `stix2` Python library (`stix2==3.0.1`) | Removed from dependencies |
| Neo4j label pattern `:STIXEntity:{PascalCase}` | Replaced by `:Entity:{TypeLabel}:{tenant_label}` |
| Sigma.js + Graphology graph visualization | Replaced by React Flow (`@xyflow/react`) + dagre/elkjs |
| Semantic zoom, FocusPanel, FilterToolbar, ActivityDrawer, AlertBadge (Delivery components) | Replaced by search-first UX with inline node components |
| `/api/graph` polling route | Replaced by `/api/search` (semantic search → Neo4j neighbors) |
| `useSemanticZoom`, `useGraphFilter`, `buildClusterGraph`, `useAlertHighlight`, `useGraphData` | Replaced by `useGraphSearch` and `useRealtimeNodes` hooks |
| M6.3 STIX Compliance & Audit Trail milestone | Removed from roadmap |
| Intelligence Community (IC) framing in all docs | Replaced with domain-agnostic language |
